# UniFiles YouTube

Browse and play music from regular YouTube in UniFiles.

## Install

1. In UniFiles, open **Media → Media sources → + → Install plugin**.
2. Paste this manifest URL:

   ```text
   https://github.com/monokaijs/unifiles-youtube/releases/latest/download/manifest.json
   ```

3. Tap **Install**, then return to **Media** and select the new source tab.

For YouTube Music, use [unifiles-youtube-music](https://github.com/monokaijs/unifiles-youtube-music). You can install both sources together.
